# REFA — 검토 노트 (보관용)

> 2026-10-21 기준. 이 프로젝트는 검토 결과에 따라 **특허 정규출원을 하지 않고 접기로 결정**했다.
> 이 노트는 **명세서와 공개 문헌만으로** 판단했으며, 코드는 검토하지 않았다. 수치와 주장을 인용하지 말 것.

## 무엇을 만들려 했나

"레니 엔트로피 기반 신호 정제 및 크래머-라오 하한 수렴형 확장 정보 필터링을 수행하는 소프트웨어 알고리즘 코어 시스템"(REFA).
레이더, 관성센서, 위성항법장치 등 여러 센서의 관측값에서 디지털 무선주파수 메모리(DRFM) 기만 재밍에 의한 가짜 관측을
레니 엔트로피로 구분해 가중치나 게이팅으로 영향을 줄이고, 확장 정보 필터(EIF)로 상태를 추정하며,
추정 오차가 크래머-라오 하한(CRB)에 가까워지도록 필터 파라미터를 조정하는 구조.
가출원: 2026-08-03 (참조번호 TB20260406).

## 확인한 문제

### 기술적으로 성립하는지 의문인 곳 (일반 지식 기준)

- **α → ∞ 가 "고에너지 극값"을 강조한다는 설명**: 레니 엔트로피는 α 가 클수록 확률이 가장 높은 값에 지배되고,
  α → ∞ 에서는 최대 확률 하나로만 결정된다(최소 엔트로피). 드물게 나타나는 극단값을 강조하려면 오히려 α < 1 쪽이 맞다.
  다만 명세서가 엔트로피를 **어떤 분포**(관측값 분포, 신호 에너지 분포 등)에 적용하는지 정의하지 않아,
  해석에 따라서는 성립할 수도 있다. 어느 쪽이든 핵심 메커니즘을 명세서만으로 재현할 수 없다.
- **크래머-라오 하한 수렴 제어**: 청구항은 "추정 오차"를 기준과 비교해 필터를 조정한다고 하지만, 실제 운용 중에는 참값을
  모르므로 추정 오차를 알 수 없다(시뮬레이션에서만 가능). 운용 중 쓸 수 있는 것은 혁신 잔차 같은 간접 지표뿐이다.
  또한 크래머-라오 하한은 필터 성능을 평가하는 기준으로 쓰이며, 필터를 그 하한까지 끌어올리는 제어 대상으로 쓰기는 어렵다.
- **구체적 방법의 부재**: 엔트로피 계산 방식(창 크기, 분포 추정), 엔트로피에서 가중치·게이팅 계수로의 변환식, 기준값이
  모두 없다. 청구항 1 은 사실상 "전처리 → 분포로 기만 관측 구분 → 가중치를 반영한 정보 필터 갱신"이라 범위가 넓다.
- **실험 결과 없음**: 성능 수치는 "목표 플랫폼에서 약 0.09ms 수준을 목표로" 한 줄뿐이며, 플랫폼, 상태 차원, 센서 수가 없다.

## 선행기술 (1차 조사, 논문·공개 자료 중심)

| REFA 구성 | 가장 가까운 기존 기술 |
|---|---|
| 엔트로피 기준으로 이상 관측에 강한 칼만 계열 필터 | Chen, Liu, Zhao, Principe, "Maximum correntropy Kalman filter", Automatica 76 (2017) |
| 레니 엔트로피를 쓰는 확장 칼만 필터 | 최소 오차 엔트로피 칼만 필터(MEE-KF)와 확장판 MEE-EKF (arXiv:1904.06617) |
| 엔트로피로 DRFM 기만 재밍 검출 | 시간-주파수 엔트로피 특징 기반 DRFM 재밍 CFAR 검출, Systems Engineering and Electronics 38(4) (2016) |
| 확장 필터로 DRFM 가짜 표적 식별 | EKF 와 네이만-피어슨 기준 기반 식별, Int. J. Antennas and Propagation (2024) |
| 혁신 잔차 기반 신뢰도와 게이팅 | 칼만 필터의 표준적인 이상치 게이팅 (일반 지식) |
| 정보 행렬 대칭화, 양의 정부호 보정, 재초기화 | 칼만 필터 구현의 표준적인 수치 안정화 기법 (일반 지식) |
| 결정론적 실행 주기, 고정소수점, SIMD | 일반적인 실시간 소프트웨어 기법 |

특허 데이터베이스(KIPRIS 등)는 검색하지 않음.

## 접은 이유

1. 핵심 구성 대부분이 공지 기술이다.
2. 고유해 보이는 부분(α → ∞ 에서의 강조, 크래머-라오 하한 수렴 제어)은 기술적으로 성립하는지가 의문이다.
3. 구체적인 방법과 실험 결과가 없어 주장을 뒷받침할 근거가 없다.
4. 출원을 줄이고 IESA 에 집중하기로 했다.

## 배운 것

- 엔트로피 같은 지표를 쓸 때는 **어떤 분포에 적용하는지**와 **차수가 무엇을 강조하는지**를 먼저 정의하기
- 운용 중에 **관측할 수 있는 양**과 시뮬레이션에서만 알 수 있는 양(참값, 추정 오차)을 구분하기
- 구성 요소의 나열이 아니라, 재현 가능한 수식과 실험으로 주장을 뒷받침하기
